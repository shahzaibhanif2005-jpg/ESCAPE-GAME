# 🎮 ESCAPE-GAME

My first Java game project!

## About
A simple text-based escape game made in Java.
You fight enemies, collect coins, and try to survive!

## How to Play
1. Run Escape.java
2. Choose 1 to Attack, 2 to Run Away
3. If enemy health = 0, you win!
4. If your health = 0, you lose!

## Files
- Escape.java - Main game
- EvenOdd.java - Even / Odd checker
- FirstLoop.java - My first loop practice
- forLoop.java - For loop practice
- NewInput.java - Input practice
